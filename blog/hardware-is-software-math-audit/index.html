硬件即软件：一笔 74% 的账是怎么对不齐的

#AI 经济#制造业#数字核验#封底估算

「硬件即软件」（Hardware Is Software）是投资人 Tomas Pueyo 在 2026-11-18 发表的文章标题，也是他的论点：硬件工程本质上是伪装成硬件的软件工程，所以 AI 吃掉软件业的那套逻辑，会原样传导到制造业，把整条价值链的成本压掉 65-75%。推理链确实值得认真对待。我把它译写整理了一遍，并做了一件原文没做的事：把能复算的账全部复算。结果比「算错了」更有意思——几个关键数字钉不死唯一的算法，而两处对照组反而精确自洽。这个反差比结论本身更有信息量。

一条论点，六段推理

原文的论证是链式的，每一环都为下一环供弹药。

第一段，硬件工程是「婴儿软件」。Boom Supersonic 创始人 Blake Scholl 在推文里给了这段论战最锋利的表述：机翼载荷进、翼梁尺寸出，热载荷进、空调系统尺寸出——一切皆计算，计算即软件，但这些计算至今靠工程师在电子表格里手搓，没有架构、没有单测、没有版本控制。他的方法论一句话能说完：“don’t design the hardware, design the algorithm for designing the hardware”（不要设计硬件，设计「设计硬件的算法」）。战果数字全部出自这条推文：涡轮机械设计工具让 1 个工程师实时完成过去 100 人×6 个月的工作；另一工具自动生成整机结构的 65%；50 人造出无音爆超音速飞机，150 人造出全尺寸超音速涡轮机。

第二段，AI 直接下场设计硬件。Casey Handmer 对 Claude 说「设计一块能用雷达检测我心率的 PCB」，拿回电路、布局、固件、软件的全套设计，唯一物理步骤是商品化的打板贴片。Handmer 由此推论：GPU 设计和 CUDA 这两条「12 个月前还不可逾越的护城河」，如今一个前沿模型花不到 100 万美元的 token，就能把两者一并重建。

第三段，智力成本是制造业的隐藏大头。R&D 占制造公司营收约 5-20%（原文引 NSF 数据），此外需求设计、文档、详细工程、实验、测量、认证、鉴定全是智力任务。类比太阳能：50 年里以 12%/年的学习曲线降本，若速度是 20%/年会提前 20 年到达同一成本点，30%/年则提前 32 年。

第四段，Idiot Index。Musk 早年算出火箭报价里原材料只占约 2%（Wired 2012 访谈），差额全是「人类智能造成的浪费」。SpaceX 的答卷：Falcon Heavy 已实现降本 98%；Starship 预期再降 93%（原文为将来时，尚未兑现），两步复合合计约 99.9%。

第五段，蓝领也在射程内。蓝白领合计占制造成本约四分之一，缺的只是划算的动作自动化；人形机器人若成功，作者判断 2-5 年内蓝领成本开始塌方。

第六段，价值链传导。制造业成本结构大致是：部件与原材料约 62%、人力约 26%、机械 3%、能源 1.8%、维护 1.5%、土地建筑 1.4%。A 公司把部件成本砍 12 个百分点、加上人力削减，总成本降约 37%；竞争把降幅让渡给客户；A 再压供应商 B，B 又压自己的供应商——三级各降 37%。「推到整条价值链」之后，原文给出两个数：总降幅 74%，剩余约 25%（原材料、能源和零星人力）。替换人力的是资本：为推理付费，加上机器人折旧。时间线上原文摆了两派：受原子世界测试周期与既得利益约束的 5-20 年派，和 AI 公司直接买下工厂改造的 1-4 年派。

链条到此闭合：智力任务被压缩 → 硬件设计被压缩 → 蓝领被压缩 → 逐级传导 → 制造业成本结构重写，采矿业成为最后的护城河。下面是复算结果。

74% 与 25%：钉不死唯一的算法

价值链那段的两个数，用哪种算法都钉不死。原文点名了三个 37% 的步骤（A 公司、供应商 B、B 的供应商），于是至少有两种重构方式。加法口径（取前两级）：37 + 37 = 74，精确命中「总降幅 74%」——但 100 − 74 = 26，推不出原文的「剩余约 25%」。三级复利口径：1 − 0.63³ = 74.995%，降幅应是约 75%，与原文的 74% 差一个百分点——但剩余 0.63³ = 25.005%，与原文「剩余约 25%」的偏差仅 0.005 个百分点。

两种读法证据对称：各钉死一个数、各对不齐另一个数，误差都在 1 个百分点上下。我把三种级数一起验：

import math

def chain_additive(r, n):
    return min(r * n, 1.0)

def chain_compound(r, n):
    return 1 - (1 - r) ** n

for n in (2, 3, 5):
    print("价值链 %d 级: 加法=%.1f%% 复利=%.1f%% 复利剩余=%.1f%%" % (n, chain_additive(0.37, n) * 100, chain_compound(0.37, n) * 100, (1 - chain_compound(0.37, n)) * 100))

cost50 = 0.88 ** 50
for rate in (0.20, 0.30):
    years = math.log(cost50) / math.log(1 - rate)
    print("学习速度 %d%%/年: 需 %.1f 年到位, 比 50 年提前 %.1f 年" % (rate * 100, years, 50 - years))

rocket = 1 - (1 - 0.98) * (1 - 0.93)
print("火箭两步复合降本: %.2f%%" % (rocket * 100))
价值链 2 级: 加法=74.0% 复利=60.3% 复利剩余=39.7%
价值链 3 级: 加法=100.0% 复利=75.0% 复利剩余=25.0%
价值链 5 级: 加法=100.0% 复利=90.1% 复利剩余=9.9%
学习速度 20%/年: 需 28.6 年到位, 比 50 年提前 21.4 年
学习速度 30%/年: 需 17.9 年到位, 比 50 年提前 32.1 年
火箭两步复合降本: 99.86%

文本无法裁决该信哪种：作者没写出算法，「推到整条价值链」也没给级数——三级是文本点名的 37% 个数（这是我的解读，不是原文字面），级数再往上推，复利口径渐近 100%，加法口径在第三级就封顶。所以对 74% 和 25% 这对数字，正确的处理不是「这笔账算错了」，而是「这笔账无法复算」：约四分之三降价的量级信号可以收下，数字本身不能当测算结果转载。

另外三处对不上的口径

第二处，人力占比漂移。第五段说蓝白领合计占制造成本 25%，隔一节的成本清单里写约 26%。有意思的是 37% 恰好等于 12 + 25——第六段推导用的其实是第五段的 25%，跟它自己清单上的 26% 反而对不齐（12 + 26 = 38）。同一个量，三处两个值。

第三处，清单不闭合。62 + 26 + 3 + 1.8 + 1.5 + 1.4 = 95.7%，约 4.3% 的成本没有科目——物流、合规、保险或别的什么都行，但清单既然摆出来当推导底座，缺口就该有个名字。

第四处，区间无推导。takeaway 把总降幅写成 65-75%，74 落在区间内，但两端怎么算出来的，原文没有交代。

放在一起看有同一个形状：口径彼此对不上——同一个量在不同段落取不同值，或者给出区间却不给推导——读者无法确定哪个是最终口径。引用这类文章时，这些数字只能各自带上段落号，当成彼此独立的数处理。

对照组：作者会算的地方算得很准

同一篇文章里有两段账经得起复算，这个对照决定了上面所有判断的分寸。

太阳能段完全可核：以 12%/年降 50 年，累计降到 0.88⁵⁰ ≈ 0.17%；若学习速度是 20%/年，到位只需 28.6 年，提前 21.4 年——原文说「提前 20 年」；30%/年则需 17.9 年，提前 32.1 年——原文说「提前 32 年」。误差都在 1.5 年以内，口径自洽，且输入是历史数据，不存在预测成分。

火箭段数学自洽，但一半输入是预期：98% 是 Falcon Heavy 的已实现数字，93% 是 Starship 的将来时预期。按作者口径复合，1 − 0.02 × 0.07 = 99.86%，与原文「约 99.9%」一致——算式没错，但「约 99.9%」能否兑现取决于 Starship 是否达到预期，它是预测的复合，不是战绩的复合。

结论要按证据收着说：作者对复利和加减法的掌握没有任何问题，价值链段更像口径没写清，而不是不会算。至于是行文疏忽还是有意取更好看的数，现有文本区分不了——审稿的标准是只描述前者，不指控后者。

哪些数字我标了待核

复算管不到事实性断言，这部分只能标注核验状态（均截至 2026-11-27）。

NASA 引用无法核实。原文说「NASA 证明了这一点」，引 NTRS 编号 20220012523 的论文：AI 设计的工业零件便宜 40%、轻 66%、设计快 85%。该页面当前返回 403，无法直接核对；检索到的文档性质线索（可能为 NASA 监察长办公室的报告类文档而非设计研究论文）同样无法证实，只能存疑。结论不变：核到原始文档之前，这三个数字不该转述，「NASA 证明了」这个措辞的强度也就无从检验。

「黄仁勋卸任」无佐证，且写法值得单独说。原文在引出 Handmer 推文时，用一句叙述句写着「在 Jensen Huang 从 NVIDIA 卸任之后」——这句话在引文块之外，是 Pueyo 本人的话，没有任何来源或不确定性标注。我在 2026-11-27 检索不到确认此事的可信报道。这不一定是假消息（检索覆盖有限），但把一个存疑的时点前提当既成事实写进叙述句、再让推论的可信度建立在它上面，比数字瑕疵更容易误导：读者会以为这是已核实的背景，而不是需要验证的断言。

战果数字全是当事方自述。100 人×6 月变 1 人实时、65% 结构自动生成、50 人造超音速飞机——出自 Scholl 本人的推文；「不到 100 万美元 token 重建 GPU 设计与 CUDA」出自 Handmer 本人的推文。没有第三方审计。还要记一笔利益相关：原文作者是 Boom 的小投资人、Handmer 公司的投资人，两个核心样本都来自他的被投企业。这不是造假指控，是证据权重问题：动机化证词该打的折扣，读者要自己打。

这类文章怎么读

把方向判断和量级数字分开结算，是我从这次复算里拿走的唯一方法论。

方向判断——制造业成本的大头是智力任务，智力任务正在被压缩，人力工资将被推理账单和机器人折旧替换——支撑来自公开统计、历史学习曲线与从业者证词（证词的证据权重见上一节），它成立与否不依赖 74% 这个数。它和按成功任务算 Token 成本讨论的是同一笔账的两个尺度：微观上你为一个成功任务付多少 token 费，宏观上整个制造业把工资单换成算力单。

量级数字——65-75%、74%、2-5 年——全部是封底估算，而封底估算的正确用法是判断数量级、暴露敏感项，不是当预测引用。这次复算恰好演示了封底估算最常见的失真方式：每一步单看都有依据，步与步的衔接口径却会滑动——加法与复利混用、25% 与 26% 漂移——滑动到一定程度，同一笔账就无法用唯一算法复原。检查别人估算的办法和检查自己的一样：把每一步的算法写成能跑的代码，让级数取文本点名的每一个值，口径就无处可藏。

原文没获转载授权，本文只摘录了必要短句；推理链是译写重述，复算与核验是本文自己的工作。数字都会过期，Pueyo 文中提到的 NVIDIA 市值「四万亿」是他写作时点（2026-11）的快照，本文所有检索与抓取同样以 2026-11-27 为截止日。

原文：Tomas Pueyo “Hardware Is Software”（Uncharted Territories，2026-11-18）
