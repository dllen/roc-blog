通俗易懂讲论文 · Paper Reading

系列定位:把每篇论文讲成「我能跟别人讲清楚」的工程笔记——核心 idea、为什么成立、踩过什么坑、对今天的工程意味着什么。 风格:比喻 + 中文工程语境 + 结构化对照表 + 工程师笔记,避免学术综述的抽象,也不只调用 API。

📘 这套方法论怎么读?

每篇论文按 3 遍阅读法 写:

  1. 第一遍(15 分钟):鸟瞰图——一句话故事 + 解决的问题 + 关键 idea。
  2. 第二遍(1 小时):拆主干——核心算法、关键公式、关键架构图,看一遍伪代码。
  3. 第三遍(半天):复现脑——作者为什么这么选?这个 idea 还能用在哪些场景?

必出 1 个输出:每篇都要写出至少一个「我接下来能用它做什么」的具体落地点——不是「很厉害」,而是「我可以在 XX 项目里这样用它」。

→ 先看 论文阅读最佳实践 拿完整方法论。

🎯 适合谁读

  • AI / 后端工程师:想搞清楚 Transformer/AlphaFold/GAN 这些「每天用但没读过原论文」的底层。
  • LLM 平台 / AI Infra 工程师:想跟上一周一篇的 LLM/Agent 论文,不被术语淹没。
  • 技术 Lead / 架构师:想从论文里抓出对工程选型真正有用的 idea,不被营销稿牵着走。

微软研究院无中央编排器的多智能体自组织框架:1024 个 worker 共享同一协作循环(收集上下文/认领子任务/行动/验证/合并),自发形成分工合作;ProgramBench 通过率从 19.31% 提升到 28.78%,pandoc 从 33.89% 提升到 55.06%。

AutoCompact 详解：让编码智能体自己决定何时压缩上下文

AutoCompact 训练编码智能体通过裁判审查 + SFT + RL 两阶段自主决定何时压缩上下文、保留什么工作状态、如何无缝衔接继续执行;SWE-bench Verified 提升 +9.2%,SWE-PolyBench +5.0%。

AutoGym 详解：从零生成完整的 RL 训练场

2026-10-15

DAIR AI 蓝图先行 gym 自动生成框架:从领域种子出发,先定义有效解空间/环境要求/验证标准再生成环境,确保可解性内建;主动课程机制随模型能力自动调整难度;摆脱手工设计 + LLM 裁判不可靠的两大痛点。

CASD 详解：让智能体从日志自己总结规则

2026-10-15

微软 CASD(Coding-Agent Skill Distillation):给编码智能体 + 整个语料库日志,让它自己写 Python 代码分析失败模式,一遍过蒸馏成行为规则;比 GEPA 提升 5.7 个百分点,成本便宜 22 倍($1.60 vs $35)。

CLM 详解：让模型自己编辑上下文

2026-10-15

华盛顿大学+Meta+MIT 联合 2026 年 CLM(Context Language Models):把上下文当文件,让模型用代码编辑管理;Suffix Cache Reuse 节省 35% 计算;BrowseComp-Plus 准确率 +11.4%,小模型受益尤其明显。

Critical-State RL 详解：多轮工具调用，只训练那一次关键调用

2026-10-15

Salesforce AI Research 用嵌套采样在多轮工具调用中找到真正的「关键调用」,只对那一轮做强化学习更新,BFCL v4 提升约 14 个百分点;训练所有轮次反而帮倒忙,因为大部分奖励变化是延续噪声。

EvoOntology 详解：给数据 Agent 配一个会进化的语义字典

2026-10-15

中国人民大学 EvoOntology:Schema/Content/Tool 三层语义本体 + MCP 协议 + Builder Agent 自动构建 + 配对评估自我演化,让 Agent 运行时动态查询业务语义;给 Claude Code / Codex 一键接入。

GAVEL 详解：给 LLM 配一张会预测后果的图

2026-10-15

GAVEL 给 LLM 配备图世界模型:独立于 LLM 的因果地图负责预演/检测/修复;成功把机器人规划成功率从 41% 提到 92%,同时推理成本更低;解决 LLM 物理约束违反/无法恢复/物体跟丢三大噩梦。

Harness-Zero 详解：把 harness 的能力蒸馏进模型权重

2026-10-15

Google Harness-Zero:用 Agent-as-Harness 生成纠错示范,微调学生模型把专用 harness 的能力内化到权重里;训练后去掉 harness(44.3%)反而比挂着 harness(41.7%)更好,行为恢复率 82.3%。

HySparse2 详解：让长上下文 Agent 的 Prefill 便宜 5 倍

2026-10-15

小米 MiMo 团队 HySparse2:两层 KV 共享(KV Bridging + KV Reuse),内层 token 级稀疏 + 外层跨解码器复用,80B-A3B MoE 上 Prefill FLOPs 降低 5 倍、KV Cache 从 12GB 压缩到 2.69GB,MRCR-v2 提升 11.30 分。

JAZ 详解：一个原语撑起记忆和自我改进

2026-10-15

MIT 2026 年 JAZ 极简智能体框架:整个框架只有一个 invoke 原语,所有能力(记忆/反思/工具)由大模型运行时自己涌现;比 MemGPT 召回率高 8%,成本降低 50%;从预设主义到涌现主义的框架哲学转变。

JEV 详解：便宜 277 倍的裁判

2026-10-15

TypeSafe AI JEV(决策专用模型)+ 级联升级:简单题用 JEV 直接判(每千次 $0.044 vs GPT-6 $12.18,差 277 倍,快 12 倍),难题目升级给 GPT-6;级联方案保留 99% 准确率,只花 57% 费用。

Jev-Mem 详解：把记忆决策从大模型手里拿走

2026-10-15

Jev-Mem 用 System-One 轻量控制器专职管记忆,System-Two 大模型只在复杂推理时介入;LoCoMo 基准 LLM-as-Judge 得分 0.777(比最强基线高 11%),记忆构建速度 6.6 倍,延迟降低 36.7%。

ScientistTwo 详解：24 个 AI Agent 自主完成科研全流程

2026-10-15

Google + 滑铁卢大学 ScientistTwo:24 个专业化 Agent 组成流水线,自主完成读论文/找问题/做实验/写论文/同行评审全流程;107 个研究问题上 80.4% 成功率,平均相对 SOTA 提升 25.2%,通过 Stanford Agentic Reviewer 评审。

Self-Organizing Agent Teams 详解：让 AI 团队自己改写协作策略

2026-10-15

斯坦福/Emory/TogetherAI 论文:AI 团队用 15 道 AIME 题目自己学会改写角色/讨论阶段/信息流动,协作通过三步流程(回顾/改写/冻结);AIME 准确率 66.7%,比最强单成员(48.8%)高 18 分,比完美路由器高 7.7 分。

SIFT 详解：让 LLM 当裁判，跑树搜索做自我改进

2026-10-15

SakanaAI / MIT SIFT:用 LLM 担任两两比较的裁判 + Bradley-Terry 模型算实力分 + 解耦树搜索,Polyglot 从 30.7% 提升到 35.1%,成本只有 DGM 的 1/10;关键洞察:裁判质量决定系统方向。

SkillGym 详解：把人类技能变成可验证的训练环境

2026-10-15

SkillGym 把人类技能指南转成 2756 个带代码验证的训练环境(覆盖 12 个类别),让 AI 真正把技能内化到模型权重里;Qwen3.5-35B-A3B 在 Terminal-Bench 2.1 上从 2.1% 提升到 21.2%,不加载技能上下文也跑赢带技能的基座模型。
