> **方法论定位**：工程师视角的论文阅读 SOP，区别于学术派的「逐字精读」，强调「读完能复现、能用、能讲」。
> **适用人群**：后端 / SRE / 应用工程师，读论文是为工程实践服务。

---

## 一、核心原则

```
每篇论文 = 鸟瞰(20min) + 精读(2-3h) + 复现(5-10h) + 1 个输出

没有输出的阅读 = 浪费时间。
```

**为什么是 3 遍而不是 1 遍**：

| 遍数 | 目的 | 失败成本 |
|---|---|---|
| 第 1 遍 鸟瞰 | 决定要不要继续读 | 低（30 min） |
| 第 2 遍 精读 | 理解核心方法 | 中（3 h）|
| 第 3 遍 复现 | 把论文变能力 | 高（10 h，但回报最大）|

**为什么必须配 1 个输出**：

- 读完后 1 周不输出 → 遗忘 80%
- 读完后 1 个月不输出 → 几乎归零
- 输出形式：笔记 / 思维导图 / 伪代码 / 真代码 / 博客 / 分享

---

## 二、第 1 遍：鸟瞰（20-30 分钟）

### 目标

**决定要不要读第 2 遍**。

### 清单（按顺序）

| # | 动作 | 时间 | 关键问题 |
|---|---|---|---|
| 1 | 读标题 + 副标题 + 摘要 | 5 min | 这篇要解决什么问题？ |
| 2 | 看所有图表（Figure 1 到 N）| 10 min | 作者想让我看到什么？ |
| 3 | 读结论最后 1 节 | 3 min | 作者自评的贡献是什么？ |
| 4 | 读引言最后一段 | 2 min | bullet list 形式的贡献清单 |
| 5 | 看 References | 5 min | 作者群 / 引用了谁 / 是否工业界 |

### 决策标准（满足 ≥ 1 条就继续读第 2 遍）

- 是当前方向的 **SOTA 或里程碑**工作
- 是 **2023 年之后**的实用工作
- 作者群是工业界大厂（Anthropic / OpenAI / DeepSeek / Google / Meta / Mistral）
- GitHub 有 **官方代码**（必有可复现性）
- 引用超过 **500 次**（社区验证）
- 否则只读第 1 遍即可，跳到下一篇

### 实战技巧

- 用 ChatGPT / Claude 给论文做 **200 字摘要**，先看摘要是否戳中你的需求
- 用 [arxiv-sanity](https://www.arxiv-sanity.com/) 找热门，避免读冷门
- 用 [Connected Papers](https://www.connectedpapers.com/) 看论文图谱，确认是不是关键节点

## 三、第 2 遍：精读（2-3 小时）

### 目标

**理解核心方法，能向别人讲清楚**。

### 清单（按顺序）

| # | 动作 | 关键产出 |
|---|---|---|
| 1 | 方法章节（Method / Approach）逐段读 | 每段 1 句话小结 |
| 2 | 所有公式逐个推导 | 在纸上重写一遍 |
| 3 | 算法伪代码重写一遍 | Markdown 或手写 |
| 4 | 实验表格逐行看 | 标注「最重要的数字」|
| 5 | 相关工作（Related Work）| 定位这篇在哪个谱系 |

### 关键心态：每段 3 问

**每个公式问 3 遍**：

- 为什么是这个形式？
- 为什么是这 3 个参数？
- 为什么是这个损失？

**每个实验问 1 遍**：

- 这是不是 cherry-picked？
- baseline 公平吗？
- 消融实验是否充分？

**每张图问 1 遍**：

- 作者想让我看什么？
- 我能从图里推出什么？
- 数据是否支持结论？

### 笔记模板（推荐 Obsidian / Logseq）

```markdown
# 论文笔记：[标题] ([arxiv:xxxx.xxxxx])

## 解决的问题
- 一句话：

## 核心方法
- 关键 idea（1 句话）：
- 关键公式 1（输入/输出/作用）：
- 关键公式 2：
- 关键公式 3：
- 算法伪代码（手写版）：

## 与已有方法的对比
- 相比 [A]：[差异 + 我的评价]
- 相比 [B]：[差异 + 我的评价]

## 实验数据
- 最重要的数字 1：[数字]（为什么重要）
- 最重要的数字 2：
- 最关键的消融：

## 我的疑问
- Q1：
- Q2：
- Q3：

## 与我项目的关联
- 能否用到：[是 / 否 / 部分]
- 用在哪：[具体场景]
- 需要改造：[什么 / 多少工作量]

## 输出物（必填）
- [ ] 200 字摘要已写
- [ ] 思维导图已画
- [ ] 伪代码已重写
- [ ] 复现代码已 commit
- [ ] 博客 / 分享已发
```

## 四、第 3 遍：复现（5-10 小时）

### 目标

**把论文变成你的能力**。

### 清单（按顺序）

| # | 动作 | 时间 |
|---|---|---|
| 1 | GitHub 找官方代码 | 30 min |
| 2 | 跑通官方 demo / 最小例子 | 1 h |
| 3 | 用 PyTorch / TF 重写（不抄，自己写）| 3-5 h |
| 4 | 在小数据集上验证 | 1-2 h |
| 5 | 对比论文报告的数字 | 1 h |

### 为什么必须做

写代码时你会发现论文里**没说但很关键**的细节：

- 学习率 / 优化器选择
- 数据增强 / 预处理细节
- 初始化 / 正则化策略
- 实现 bug（是的，论文也有 bug）

这些是论文"潜知识"，只有复现才会暴露。

### 复现完成标准

- 数字与论文误差 **≤ 5%** 即合格
- 误差 5-15%：可能缺某个细节，找论文附录 / GitHub issue
- 误差 > 15%：可能没复现对，回去对照代码

### 复现产出（必出 1 个）

- 1 个 GitHub 仓库（README + 代码 + 测试）
- 1 篇博客「我是怎么复现的」
- 1 张「论文宣称 vs 我的数字」对比表
- 1 个 issue / discussion（在官方仓库）

## 五、4 个加速技巧

### 1. 倒着读

```
结论 → 实验 → 方法 → 引言
```

先看「宣称做到什么」，再看「怎么证明」，再看「怎么做的」，最后看「为什么做」。
**适合**：评估论文价值，决定要不要精读。

### 2. 图驱动

```
所有 Figure → 配图段落 → 公式 → 算法伪代码
```

图是论文最浓缩的表达，先看图能快速抓住 70% 的核心 idea。

### 3. 对比读（同步读 3-5 篇）

不要一篇一篇串行读，而是**同一主题的 3-5 篇同时打开**：

- 同时读 FlashAttention 1 / 2 / 3
- 同时读 vLLM / SGLang / TRT-LLM 的 attention 实现
- 同时读 ReAct / Reflexion / AutoGPT 三种 Agent 范式
- 同时读 GPT-2 / GPT-3 / LLaMA-1 / LLaMA-2 看 scaling 规律

**为什么**同步对比能让你看清每篇的「独特点」和「通用套路」。

### 4. 教学相长

读完立刻给同事 / 公众号读者讲一遍：

- 讲 30 分钟 > 读 3 小时
- 讲不清楚的地方 = 你没懂的地方
- 输出倒逼输入

## 七、节奏建议（90 天读 12-18 篇精读）

| 阶段 | 节奏 | 论文类型 |
|---|---|---|
| 第 1-30 天 | 每周 2-3 篇鸟瞰 + 1 篇精读 | 综述 + 里程碑论文 |
| 第 31-60 天 | 每周 1 篇精读 + 1 篇复现 | SOTA 工作 |
| 第 61-90 天 | 每周 1 篇复现 | 即将用到项目里的论文 |

**总目标**：90 天内

- **20-30 篇**鸟瞰
- **12-18 篇**精读（带笔记 + 思维导图）
- **4-6 篇**复现（带代码 + 博客）

---

## 八、必出 1 个输出（关键！）

每读完一篇，必出**至少 1 个**：

| 输出类型 | 难度 | 时间 | 价值 |
|---|---|---|---|
| 200 字摘要 | ★ | 10 min | 固化短期记忆 |
| 1 张思维导图 | ★★ | 30 min | 看清概念依赖 |
| 1 段伪代码 | ★★ | 30 min | 能讲给别人 |
| 1 个代码实现 | ★★★ | 5-10 h | 复现能力 |
| 1 篇博客 | ★★★ | 5-8 h | 倒逼输入 |
| 1 次团队分享 | ★★★ | 8-10 h | 软技能 + 影响力 |

**推荐组合**：

- 鸟读 30 篇 → 不需要输出（只做笔记卡片）
- 精读 15 篇 → 笔记 + 思维导图 + 伪代码
- 复现 5 篇 → 代码 + 博客

## 九、最常见的 5 个坑

| # | 坑 | 怎么避 |
|---|---|---|
| 1 | **一上来就从头读** | 先看标题/摘要/图表，20 min 决定值不值 |
| 2 | **公式恐惧症**（跳过所有公式）| 至少看懂每个公式的「输入/输出/作用」3 信息 |
| 3 | **不写笔记** | 用上面的 Obsidian 模板，每段写 1 句话小结 |
| 4 | **不做输出** | 90 天后只「看过」= 没看过 |
| 5 | **只读 SOTA**（忽略里程碑） | FlashAttention 1 比 FA3 更值得精读（基础） |
