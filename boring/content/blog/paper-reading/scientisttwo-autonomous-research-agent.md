## 一句话总结

ScientistTwo 是一个由 Google 和滑铁卢大学研发的"AI 科研梦之队"——24 个专业化 AI Agent 组成流水线，自主完成从读论文、找问题、做实验、写论文到模拟同行评审的全流程，无需人类插手一件事，最终发表的论文居然通过了顶会评审门槛，部分指标还超过了人类学者的平均水平。

---

## 背景：AI 搞科研，能走多远？

过去几年，AI 辅助科研已经不是什么新鲜事了。但仔细看看这些"辅助"到底做了什么？大多不过是**帮科学家调调超参数、跑跑基准测试、写写代码框架**——本质上还是"工具"，不是"研究者"。

真正的问题是：AI 能不能独立完成一个完整的研究周期？

这个周期是什么样的？

```text
读论文 → 发现问题 → 提出假设 → 写代码做实验 → 分析结果 → 消融验证 → 写论文 → 同行评审
```

如果每一步都要人类参与，那 AI 充其量是个"高级打字机"。但如果 AI 能独立跑完整个闭环呢？那就完全是另一回事了。

ScientistTwo 就是对这个问题的正面回答，而且答案相当激进：**能。而且做得很不错。**

---

## 核心方法：六阶段自主发现循环

ScientistTwo 的设计理念可以理解为一个**自动化工厂流水线**——一个研究问题进去，一篇符合顶会标准的论文出来，中途无需人类干预。

整个流水线分为六个阶段，每个阶段由专门的 AI Agent 负责：

### 阶段 1：发现具体问题（Idea Generation）

第一步的关键原则是：**想法必须针对具体局限性，而非泛泛创新**，从而保证后续实验有 baseline 可对比。

### 阶段 2：快速筛选——先小规模验证想法

新想法不可能每个都值得全力投入。ScientistTwo 先在**数据子集**上快速验证——比如用 1000 条数据而非 100 万条。

这个阶段相当于"预选赛"：只跑通预选的想法，才能进入全量实验。这有效控制了计算成本，也避免了把时间浪费在错误方向上。

### 阶段 3：全量实验——在完整基准上验证

通过预选的想法进入正式实验阶段。**Coding Agent** 在完整基准上实现代码并运行实验。

这里有个很有意思的设计：实验结果不仅用来判断想法是否有效，还会被用来**迭代改写想法本身**——成功和失败的实验痕迹都被保留，为后续分析提供素材。

### 阶段 4：消融研究——搞清楚到底是哪个组件在起作用

光证明"我的方法比 SOTA 好"是不够的，还需要搞清楚：**到底是哪个组件在贡献这个提升？**

**Analyzer Agent** 会系统性地移除各个组件——关掉这个技巧、简化那个模块——隔离因果来源。这就像医学里的"控制变量法"：你想知道某种药有没有效，就得把它单独拿出来测试。

消融研究不只是为了发论文，更重要的是**验证假设的因果链条**是否真的成立，防止 AI 自欺欺人。

### 阶段 5：撰写手稿——把发现写成规范的论文

**Writer Agent** 把研究成果转化为符合学术规范的论文手稿。

但这里有个严格的对齐检查：手稿里写的每一个方法细节，必须和代码仓库完全一致。AI 不能"写一套做一套"。

### 阶段 6：同行评审——模拟顶会审稿人的挑剔眼光

最后一步：**Peer-Reviewer Agent（代号 ScholarPeer）** 对手稿进行模拟同行评审。

评审完了还不算完——**Rebuttal Agent** 针对评审意见设计新的实验，用有针对性的结果来回应批评。

**Meta-Review Agent** 则监督整个循环，判断论文是否达到了接受标准。如果没有，继续迭代改进。

## 24 个 Agent 如何协同？

整个系统由**24 个专业化 Agent**组成，用"冻结" LLM（不训练新权重）的方式运行。关键是引入了"**系统性摩擦**"——让不同 Agent 相互对抗、相互审查，从而捕捉错误、防止幻觉。

举个具体例子：

- **局限性提取器**提出的问题，**Critic Agents** 会审查可行性
- **Writer Agent** 写的手稿，**Code Audit Agent** 会检查是否和代码描述一致
- **Peer-Reviewer Agent** 提出的批评，**Rebuttal Agent** 会设计实验来反驳

这种"对抗式设计"有效抑制了单 Agent 容易产生的幻觉和错误传播问题。

### 三大完整性保障机制

| 机制 | 作用 |
|------|------|
| **Validation Filter** | 实验后消除违反规则的作弊方案 |
| **Search-Augmented LLM** | 辅助参考文献校对，防止引用幻觉 |
| **Code Audit** | 确保手稿描述与代码完全一致 |

系统还要求所有实验输出必须是**自包含、可复现的脚本**——Reproducibility 从一开始就被强制执行。

## 实验效果：真的过了顶会评审？

ScientistTwo 在 107 个研究问题上进行了评估（来自 ICLR、ICML、NeurIPS 等顶会），覆盖 8 大 AI 领域：LLM、机器人学、神经科学、语音、鲁棒性、强化学习、博弈论、隐私、优化、时间序列。

### 核心数据

| 指标 | 数值 |
|------|------|
| **成功率** | 80.4%（86/107） |
| **相对 SOTA 平均提升** | 25.2% |
| **ScholarPeer 平均评分** | 7.5/10 |
| **ScholarPeer 接受率** | 91.9% |
| **Stanford Agentic Reviewer 评分** | 5.7/10 |
| **Stanford Agentic Reviewer 接受率** | 72.1% |
| **平均执行时间** | ~2.5 天/任务 |
| **平均成本** | ~$3,765/任务 |

关键结论：**ScientistTwo 是唯一在 Stanford Agentic Reviewer 上通过 0% 基线的系统**——其他所有基线系统都没有达到该评审的通过门槛。

### 和人类学者比怎么样？

在自动评审下，ScientistTwo 生成的论文**平均得分超过了 ICLR 2026 和 NeurIPS 2025 的已接受论文**。不过，最顶尖的 Spotlight 级别质量仍未达到——换句话说，中等偏上的论文水准有了，顶级论文还差点意思。

### 迭代叠加效应

更令人惊讶的是，系统具备**迭代叠加能力**——在一次成功改进的基础上再次运行，三次迭代后累计获得**28.7% 的总增益**。

这意味着什么？AI 不只是能完成一个完整的研究周期，还能**在成功的基础上继续探索**，像人类学者一样积累知识、层层推进。

### 完整性审计：没有作弊

担心 AI 会"作弊"？论文专门做了 CoE 完整性审计：

| 审计维度 | 结果 |
|----------|------|
| 分数可复现性 | ✅ 所有报告分数均可复现 |
| 规范合规性 | ✅ 零违规，无 reward hacking |
| 引用准确性 | ✅ 1814 条引用中零幻觉 |
| 方法-代码一致性 | ✅ 49 篇抽检论文全部对齐 |

消融实验还发现，如果移除 Refinement Agent，系统在每个检查类别中都会出现零星失败，说明这些保障机制并非可有可无。

## 为什么这篇值得注意

**第一次真正实现"端到端无人干预"**

之前的 AI 辅助科研工具，要么只做超参数调优，要么只能生成代码片段，从未实现过如此完整的闭环。ScientistTwo 是第一个真正做到"研究问题进去，论文出来，全程无人插手"的系统。

**多智能体协同而非单 Agent**

之前很多 AI 系统是"单兵作战"，一个 Agent 包打天下。ScientistTwo 用了 24 个专业化 Agent，通过"对抗式摩擦"相互校验，架构设计更有利于保证输出质量。

**迭代能力意味着"可持续科研"**

28.7% 的迭代叠加增益说明，AI 不只是能完成一个研究周期，还能在已有成果上持续深耕。这为"AI 可持续推进科学研究"这一愿景提供了第一个实证。

**完整性保障是可复现科研的基础**

零引用幻觉、代码-手稿完全对齐、可复现分数，这些完整性保障机制证明了自动化系统也能满足科研诚信的基本要求，是后续工作的基础。

**部分指标超过人类学者平均水平**

在自动评审下超过顶会已接受论文的平均水平。如果这个结论经得起后续验证，将是 AI 科研能力的一个标志性节点。

---

## 局限性：它还不是全能选手

- **Spotlight 级别论文**：最顶尖的质量还未达到
- **跨学科泛化**：目前只在 AI 领域测试，对生物、化学等实验科学的泛化能力未知
- **计算成本**：平均 $3,765/任务的成本还不算低
- **长期稳定性**：迭代链的长期稳定性仍需验证

---

## 总结

ScientistTwo 的出现，第一次让人看到了 AI **自主完成完整科研周期**的可能性。它不是一个更强的代码生成器，而是一个能**提出假设、设计实验、分析因果、写论文、应对评审**的完整研究者。

这可能标志着 AI 科研能力的一个转折点：从"辅助工具"到"研究伙伴"，再到"自主探索者"。

当然，它目前还有明显的局限性，Spotlight 级别的论文还没达到，成本也不低。但它展示的方向是清晰的：**AI 不只是能帮科学家干活，它自己就能搞科研。**
