写这篇的原因很具体：我在自己的笔记库里读到这门第一性原理大模型课程的「43 课 · 因果链驱动」摘要，准备顺着它安排学习顺序时，发现课数对不上——课程站首页写「34 课」，仓库 README 写「40+ 门课」，而笔记里记的是「43 课」。三个数都不是真的。

实际数一遍是 **48 课、8 个部分**，每课恰好 6 张卡片。这门课由推荐算法工程师 zhuangzhaoyeye 维护，仓库 [zhuangzhaoyeye/llm_course](https://github.com/zhuangzhaoyeye/llm_course) 用 MIT 许可，每课一个独立 URL，在线阅读在 <https://zhuangzhaoyeye.github.io/llm-course/>，国内镜像 <https://learn.taleverse.cn/>。本文做两件事：先把课程的现状核清楚（含四处课数不一致的实测），再把它和本站已经写过的 LLM 文章逐条对照，指出哪些内容不必再读、哪些还是空白。

## 一、四处课数，四个答案

先把分歧摆出来。仓库的 GitHub 简介写「34 课」，课程站首页的 `<title>` 也写「34 课」，仓库 README 正文写「40+ 门课、每课 6 张卡片」，而我的笔记里写「43 课 · 因果链驱动」。三者互不一致，且都是二手转述。

我按课程站自己的导航数了一遍：**8 个部分、48 课**，第 1 课到第 48 课连续编号，每课对应一个 `lesson-N.html`（第 1 课的内容直接放在首页，`lesson-1.html` 并不存在）。抓取全部 47 个独立页面核对卡片数，**每一课都恰好 6 张卡片**，无一例外——README 里「每课 6 张卡片」这句是准确的。

「每课 6 张卡片」不是排版巧合，而是这门课的结构约束：每张卡片自带一条问题、知识背景与一段「完整走查」，每课再有一条 6 步的**推理链**，把这一课的内容串成「约束 → 被逼出来的解法 → 下一步的约束」。

```text
第一部分 · 认知衔接      第 1-6 课    Transformer 回顾 / 结构全景 / 五大改造 / Tokenization / 逐层解剖 / LLM 全景图
第二部分 · 训练范式      第 7-12 课   Scaling Laws / 数据工程 / 预训练全流程 / SFT / 对齐 / 推理模型与 RLVR
第三部分 · 训练与推理工程 第 13-19 课  分布式训练 / 显存账本与混合精度 / KV Cache / 量化与压缩 / 微调工程 / 推理引擎 / 大模型评测
第四部分 · Agent 工程    第 20-28 课  提示工程 / 从 Prompt 到 Agent / 工具调用 / MCP / 记忆与 RAG / 规划与反思 / 多智能体与协议 / Agent 训练 / Agent 评测与生产化
第五部分 · 自主研究      第 29-34 课  自主度分级 / 文献锚定与选题 / 假设规划与搜索 / 长时程执行与状态 / 验证复现与评审 / 报告成本与责任
第六部分 · 前沿拓展      第 35 课     决策模型
第七部分 · 后训练范式    第 36-43 课  范式地图 / 奖励模型 / RLHF 与 PPO / DPO / DPO 变体族 / 在线与无参考优化 / 推理强化 / 选型判据

```

这 48 课里，「计算走查」是贯穿全课的手法：每张卡片用一个最小真实例子把机制算到底。README 举的三个例子分别是第 21 课的 0.95¹⁰ ≈ 0.599、第 17 课的 LoRA r=8 把 16,777,216 个数压到 65,536 个（256 倍）、第 15 课 70B 模型 8K 上下文的 KV Cache 为 2.5 GiB。这些数字我抽查了第 21 课与第 25 课，页面里确实带着完整的算式。

## 二、多步任务的错误是乘性累积的

第 21 课（从 Prompt 到 Agent）和第 25 课（规划与反思）都从同一个算式出发：单步 95% 的正确率，作用在 N 步上，成功率是 p^N，不是 N × p。

这个数我实算了一遍，顺便发现课程内部有一处不一致：第 25 课把 20 步印成「0.358」，而第 22 课把同一个数印成「0.359」。

```python
for n in (5, 10, 20):
    p = 0.95 ** n
    print("%2d 步  0.95^%d = %.4f  三位小数 %.3f  至少错一步 %.1f%%"
          % (n, n, p, p, (1 - p) * 100))
```

```text
 5 步  0.95^5 = 0.7738  三位小数 0.774  至少错一步 22.6%
10 步  0.95^10 = 0.5987  三位小数 0.599  至少错一步 40.1%
20 步  0.95^20 = 0.3585  三位小数 0.358  至少错一步 64.2%
```

真值是 0.3584859224…，保留三位小数应为 0.358，所以第 25 课是对的，第 22 课的 0.359 是四舍五入时多进了一位（两位小数的「约 64%」两页一致，都对）。差异极小，但这类偏差值得记一笔：**同一门课的相邻两页印同一个数，对不上时得回算，不能默认其中一页正确。**

这个算式本身是第 25 课的论证起点：单步 95% 听着很高，10 步只剩约六成，20 步只剩约三成五。第 25 课的解法是「先花 1 步做计划」，把每步正确率抬到 0.99，10 步全对率升到 0.99¹⁰ ≈ 0.904——代价是多一次调用（约 9% 的步数），换 +0.306 的成功率。第 22 课（工具调用）用同一套口径讲 schema + strict：20 次调用单次 0.99，全对率 0.818，至少错一次降到约 18%。

## 四、真正的空白

反过来，把这份差集倒过来看，才是这门课对本站读者的真正增量。我在全站文章里逐词检索过下面这些主题，命中数为 0：

- **第五部分「自主研究」全六课（第 29-34 课）**：自主度分级、文献锚定与选题、假设规划与搜索、长时程执行与状态、验证复现与评审、报告成本与责任。这是最大的空白——本站关于「怎么把研究做成可交付的东西」的讨论，几乎都散落在 Harness 与软件工厂那几篇里，没有一篇正面处理「Agent 自主做研究时的选题、验证与复现」。
- **第 25 课 规划与反思**：本站写过 Agent 循环与 Token 成本，但没有系统讲规划粒度、树搜索式分解与语言化反思。
- **第 8-9 课 数据工程与预训练全流程**：本站只覆盖了 SFT 之后的部分（数据流水线、评测、推理），预训练之前的数据与训练全流程是空白。
- **第 14 课 显存账本与混合精度**：本站提到混合精度，但「显存账本」这个把显存逐项算清楚的方法没有专门文章。
- **第 40-42 课 DPO 变体族、在线与无参考优化、推理强化**：本站的后训练文章覆盖 RLHF/DPO/GRPO 主线，但 GSPO、RLOO、REINFORCE++ 一族与 R1-Zero 这条推理强化分支没有展开。
- **第 43 课 前沿收口与选型判据**：给方法选型判据的文章，本站没有对应的一篇。

这些空白大多是「方法论 + 可计算」型内容，和本站现有文章的调性一致，补进来不会破坏版式。

## 五、怎么用这门课

节奏上，这门课适合**按部分跳读，而不是从头顺读**。每课独立 URL、免登录，标题即入口，配合上面的差集表，可以直接定位到需要的部分。

有一个使用上的坑值得提醒：课程内部同一数字可能印得不一样（前面第 22 与第 25 课的 0.358 / 0.359 就是），而「计算走查」是这门课的核心卖点，遇到具体数字时**回算一遍比相信页面更可靠**。课程自己也标了某些数字是示意取值（如第 25 课的 0.99 明确写着「为示意取值，用于演示杠杆方向，非某模型实测」），这种标注要当真看。

许可方面，仓库是 MIT 许可，可以自由引用与改编；课程页面的内容同样可以按这个许可处理，引用时注明出处即可。

## 六、边界

- 本文只核了**课程结构与内容分布**，没有逐课评判教学质量。48 课我只抽读了第 2、3、6、12、20、21、22、25、45 课，加上全部 47 个页面的卡片数与导航结构；「每课 6 张卡片」是全量核对，「课数 48」是按导航数出来的，其余判断基于仓库 README 与抽查。README 引用的第 15、17 课算式（KV Cache 2.5 GiB、LoRA 压缩 256 倍）我核了算术，但未通读该课正文。
- 第 2、3 节引用的算式来自第 21、22、25 课；0.358 / 0.359 的不一致是我在核对时发现的，课程并未自行标注。
- 第 3、4 节的「已覆盖 / 空白」是**与本站现有文章的对照**，不是对课程本身的价值评判——空白只说明本站还没写，不说明这几课更重要。
- 课的总数仍在长（README 写「持续新增」），本文的 48 课是 2026-11-24 抓取的快照。

## FAQ（六、常见问题）

**现在到底是多少课？**
48 课、8 个部分。按课程站导航计数，全站每课独立页面恰好 6 张卡片。写「34 课」的是仓库简介和首页标题，写「40+ 门课」的是 README 正文，写「43 课」的是我自己的笔记——都不准确。

**课程内容和本站已有的 LLM 文章重复吗？**
机制层面重复不少。Transformer 机制、SFT、后训练主线、推理引擎、KV Cache、评测、提示工程、RAG、Agent Harness 这些，本站都已有专门文章，按第 3 节的表跳读即可。真正的增量集中在第五部分「自主研究」六课、第 25 课规划与反思、第 8-9 课数据与预训练、第 42 课推理强化这几块。

**0.95²⁰ 到底是 0.358 还是 0.359？**
0.3584859224…，保留三位小数是 0.358。第 25 课印 0.358 是对的，第 22 课的 0.359 多进了一位。两页都写的「约 64%」正确（1 − 0.3585 ≈ 64.2%）。

**需要按顺序学吗？**
不必。课程是因果链组织，但每课独立成篇，可以按主题定位。第三部分之后（训练与推理工程、Agent 工程）的依赖更明显一些。
